# 📌 Gestor de Campanhas Sociais

## 📖 Sobre
Projeto desenvolvido para ser um sistema completo para a criação e gestão de campanhas sociais, contendo funcionalidades de cadastro e login.

---

## 🚀 Tecnologias
- Html  
- Css  
- JavaScript  
- Node.js  
- Express.js  
- SQL  

---

## ⚙️ Funcionalidades
- Autenticação de usuários  
- CRUD completo  
- Integração com API  

---

## ▶️ Como rodar
git clone https://github.com/bruninxsz/Gestor-Campanhas-Sociais/ 
npm install 
node App.js
